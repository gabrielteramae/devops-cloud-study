# devops-cloud-study

Estudos práticos de DevOps e Cloud — Kubernetes, AWS, Azure, GCP, Terraform, CI/CD, observabilidade e mais. Teoria + labs hands-on.

## 📌 Sobre

Repositório de estudos organizado por tecnologia. Cada pasta contém:
- `teoria.md` — conceitos-chave, quando usar, arquitetura
- `pratica/` — labs, scripts e configs de exemplo
- `notas.md` — troubleshooting e problemas resolvidos no caminho
