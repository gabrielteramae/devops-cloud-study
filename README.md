Repositório de estudos práticos de DevOps e Cloud, cobrindo desde fundamentos de Linux até Kubernetes, cloud providers, IaC, CI/CD e observabilidade.

## Sobre

Este repositório documenta minha trilha de estudo em DevOps e Cloud Computing, organizada por tecnologia. Cada ferramenta possui teoria explicada em português e um laboratório prático (`pratica/`) com comandos e exercícios reais, seguindo uma progressão lógica: fundamentos de sistema → containers → cloud → automação de infraestrutura → CI/CD → observabilidade → rede e segurança.

## Funcionalidades

- Teoria resumida e objetiva por tecnologia (`teoria.md`)
- Labs práticos com comandos executáveis (`pratica/`)
- Checklist de progresso por trilha
- Notas de troubleshooting documentando problemas reais encontrados no caminho
- Estrutura pensada para complementar formação em Sistemas de Informação e experiência prévia com automação (Python, Azure Databricks, SQL)

## Stack em estudo

- **Fundamentos:** Linux, Git, Bash
- **Containers:** Docker, Kubernetes
- **Cloud:** AWS, Azure, Google Cloud
- **IaC & Config Management:** Terraform, Ansible
- **CI/CD & GitOps:** GitHub Actions, Jenkins, Helm, Argo CD
- **Observability:** Prometheus, Grafana, ELK Stack
- **Networking & Security:** Nginx, Vault
